CUSTOMIZE PHOTOS
----------------
The six PHOTO boxes in index.html can later be replaced with:
<img src="photos/photo1.jpg" alt="Memory 1">

Create a folder named "photos" and put the images inside it.

CUSTOMIZE MUSIC
---------------
A music player is intentionally not included yet because the song
has not been chosen. Once you choose the song, add a local file and
we can add a music button safely.

GITHUB PAGES
------------
Upload these files to a GitHub repository.
Repository Settings -> Pages -> Deploy from branch -> main -> /(root).
GitHub will provide the shareable website link.

TIP
---
Replace the placeholder memories and letter with Abinesh's real words
for a much more personal result.
